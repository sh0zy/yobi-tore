# 予備トレ

司法試験予備試験のアウトプット学習Webアプリです。短答・論文・口述の練習と、正誤や確信度に応じた復習を、ログインなしで行えます。

アプリを開く：https://sh0zy.github.io/yobi-tore/

- 会員登録は不要です。学習記録・答案・ノートは利用者のブラウザの中（端末ごと）に保存し、サーバーには送信しません。
- 端末どうしの同期はありません。機種変更などには、設定の「バックアップを書き出す」で作ったファイルを使ってください。
- スマホでは、ブラウザの「ホーム画面に追加」でアプリのように使え、一度開いたあとはオフラインでも使えます。

## 教材の出典と利用条件

- 問題文・正解・出題の趣旨・口述試験のテーマ：法務省ウェブサイト（https://www.moj.go.jp/jinji/shihoushiken/shikaku_saiyo_index.html ）の公表資料を加工して作成。公共データ利用規約（第1.0版）に基づき、出典を表示し、PDFの改行・字下げを整える加工をしています（文言は変えていません）。
- 条文：e-Gov法令検索（https://laws.e-gov.go.jp/ ）の法令APIを利用し、表示形式を整えて掲載。
- 解説・ヒント・確認観点・口述の練習用の問いはアプリが作成したもので、専門家の監修は受けていません。各教材の出典・確認状態はアプリの「教材」画面に表示しています。

このリポジトリには、公開用のビルド済みファイルだけを置いています。
